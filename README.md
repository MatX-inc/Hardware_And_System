# Hardware_And_System

The repository is created as a place to store and share collaterals generated by hardward team, including SoC/Package/PCB/System/Thermal etc.

SiliconInterposer folder should contain:
1) uBump map
2) C4 bump map
3) RTL or netlist
4) Power connectivity

PackageSubstrate should contain
1) BGA balmap
2) netlist


All2All_Connection should contain:
1) connectivity information for die-to-die.
