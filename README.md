# Hardware_And_System

The repository is created as a storage of code, and a place to share the code/IP generated by hardward team, including Package/PCB/System/Thermal etc.

In All2All_Connection:
It is a platform that import/export the connectivity among large number of dies. 
It is written in HTML and it basically access a database saved in sqlite.
The goal is to make it easy to query/add/edit the connectivity information for die-to-die connection.
