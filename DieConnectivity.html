Import Connections from CSV

Import multiple connections from a CSV file. New dies and components will be created automatically.

Required columns: source_die, target_die, components

Components format: component_type:component_id (separated by comma for multiple components)

Example: D.0.0.0.0, D.1.0.0.0, flex-cable:F001, board:B001, connector:C001

Note: Components are added sequentially in the order they appear in the components column. Dies and components not in database will be created automatically.

Variable chain lengths: Different rows can have different numbers of components. Use comma to separate multiple components in the same line.
